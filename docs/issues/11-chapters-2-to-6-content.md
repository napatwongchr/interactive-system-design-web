# Issue 11 — Chapters 2–6 Lesson Content

**Scale milestones: 10 → 1,000 → 10,000 → 100,000 users → "Design It Right"**

## What to build

Write and implement all lesson content for Chapters 2 through 6, following the patterns established in Chapter 1. Each chapter can be worked on independently in parallel once Chapter 1 (Issue 10) is complete and the content patterns are proven.

**Chapter 2 — "10 Friends Use It"** (10 users)
Why APIs exist, client-server architecture, environment variables and secrets.

**Chapter 3 — "It Goes Viral"** (1,000 users)
What breaks first, server CPU/memory limits, database bottlenecks, reading error logs.

**Chapter 4 — "You Fix It"** (10,000 users)
Caching, CDN, database indexing, async operations.

**Chapter 5 — "You Scale It"** (100,000 users)
Load balancers, horizontal vs vertical scaling, message queues, stateless servers.

**Chapter 6 — "You Design It Right"**
System design principles, reading and drawing architecture diagrams, trade-offs (SQL vs NoSQL, consistency vs availability), how to think about scale before you need it.
